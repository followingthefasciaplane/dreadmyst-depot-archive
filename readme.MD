## dreadmyst historical archive

this repo archives all 63 updates in the manifest history of dreadmyst. 

- `manifest.md` contains a chronological ordered index.
- there are server binaries are in **3741278284231581632**, **7227645908100722033** and **5010033847135943523**.
  
## note

i have removed the `content` folder containing the assets considering it was just 38gb of duplicated files.  
but if you really want them, i've included a SteamCMD script that you can use to download the manifest history yourself:

```
./download_manifests.sh your_steam_username
```

**you need to own the game in your library to have access to the historical builds.**
